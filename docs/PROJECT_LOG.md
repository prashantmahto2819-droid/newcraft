## 2026-11-18 — Creation of the Tulika suite
**Goal (user, Hindi chat):** build own CorelDRAW/Adobe-style app suite from the open-source ArtCraft apps, run on
Cloudflare + Supabase and as Windows/cross-platform apps; name must avoid copyright/trademark trouble.
**Decisions**
* Name: **Tulika (तूलिका)** — Tulika Vector / Photo / Film / PDF. Risk noted: a Chennai children's-book publisher uses
  "Tulika" (different class); user must run IP India/WIPO searches (docs/TRADEMARK-CHECKLIST.md).
* Separate apps under one suite (shared login/storage/dashboard), not one giant app.
* Fork upstream snapshots (MIT OR Apache-2.0) from github.com/storytold/{vectorcraft,photocraft,filmcraft,pdfcraft};
  commits recorded in `shared/UPSTREAM_COMMITS.txt`. PrintCraft = old name of PdfCraft (same repo content).
* Rebrand = user-visible strings only; internal crate/identifier/binary names stay `*craft` (safe merges, no blind mass rename).
* ArtCraft marks (docs/brand logos, dragon/owl/lion app icons, "Learning Machines LLC" manufacturer, `ai.storyteller.*`
  ids, installer GUIDs) removed/replaced; all new art generated by `tools/make_icons.py`. Upstream NOTICE/LICENSE/ATTRIBUTION kept.
**Done**
1. Cloned 4 upstream repos, copied into `apps/{vector,photo,film,pdf}`; history squashed into clean commits (raw import with ArtCraft logos was never pushed).
2. `tools/rebrand.py` (strings/comments only in .rs via tokenizer; WiX attributes only; URLs -> this repo) and `tools/finish_rebrand.py` (ids `in.tulika.*`, company, GUIDs, file renames, READMEs, nested AGENTS/CLAUDE removed).
3. Original icons/logos (`tools/make_icons.py`); colours: vector teal, photo rose, film violet, pdf amber.
4. `platform/supabase/migrations/0001_tulika_init.sql` (profiles, projects, brand_kits, private storage bucket, RLS) and
   `platform/web` dashboard (Hindi, supabase-js via esm.sh, config via `config.js`; CI generates it from secrets).
5. Workflows: `desktop.yml` (Win/Mac/Linux binaries), `web.yml` (trunk WASM + Cloudflare Pages deploy).
6. Docs: README, NOTICE, BUILDING, UPSTREAM, TRADEMARK-CHECKLIST, CODE_MAP, this log.
