## 2026-11-18 — Creation of the Tulika suite
**Goal (user, Hindi chat):** build own CorelDRAW/Adobe-style app suite from the open-source ArtCraft apps, run on

  commits recorded in `shared/UPSTREAM_COMMITS.txt`. PrintCraft = old name of PdfCraft (same repo content).

## 2026-11-21 (photo web crash) — "time not implemented on this platform"
- User screenshot: /photo/ stops on start with a panic in std `Instant::now()` (wasm has no std clock).
