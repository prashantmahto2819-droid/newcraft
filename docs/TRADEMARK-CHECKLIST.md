# Name and trademark checklist (do before public launch)

The code licence (MIT/Apache) covers copyright. A trademark is a separate thing: nobody can promise that
a name is free without a search. Do these steps for "Tulika" (and each app name):

1. India: https://ipindiaservices.gov.in/tmrpublicsearch/ — Wordmark search for "Tulika", Class 9 and 42 (software), also 41.
   Note: "Tulika" is also the name of a children's book publisher; it is a different class, but check.
2. World: https://branddb.wipo.int
3. Domains: tulika.in / .com / .app (or a variant) and the GitHub / Instagram / YouTube handles.
4. If clear, file a trademark application at IP India (a lawyer is cheap relative to a rebrand later).
5. Replace the bundle ids `in.tulika.*` once you own a domain (Flatpak/macOS ids are reverse-DNS).
6. Never use "Adobe", "Corel", "Photoshop", "Illustrator", "Premiere", "Acrobat", "CorelDRAW" in product names,
   ads or store listings. Naming file formats (PSD, AI, PDF) inside the apps is fine.
