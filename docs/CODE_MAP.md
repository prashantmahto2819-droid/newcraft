# Code map (read this first instead of reading the code)

Four independent Cargo workspaces under `apps/`. Edition 2024. UI = egui/eframe (+ wgpu). Dependencies come from
git forks `storytold/craft-libs`, `storytold/egui`, `storytold/winit` (pinned by rev in each `Cargo.lock`) —
if those repos disappear, builds break; consider vendoring/mirroring them.

| app dir | upstream name | main package (desktop) | web package | native file format | size (rs lines, approx) |
|---|---|---|---|---|---|
| apps/vector | VectorCraft | `vectorcraft` (apps/vectorcraft) | `vectorcraft-web` | `.vectorcraft` (JSON) | ~1.5M |
| apps/photo  | PhotoCraft  | `photocraft` | `photocraft-web` (+ `photocraft-web-boot`) | `.pcraft` bundle | ~0.9M |
| apps/pdf    | PdfCraft    | `pdfcraft` | `pdfcraft-web` (+ `pdfcraft-ocr-worker`) | PDF | ~0.7M |
| apps/film   | FilmCraft   | `filmcraft` | `filmcraft-web` (no Trunk.toml yet) | `.fcproj` | ~0.5M |

## Common layering (same pattern in all four)
`doc/format/geom/...` (pure data) -> `engine` (sessions, history, selection, **command registry**) -> `ui-egui`
(menus, panels, tools, canvas) -> `apps/<name>` (desktop shell) / `apps/<name>-web` (wasm shell) / `apps/<name>-cli`
(headless + MCP server). Every action is a registered *command* in `crates/engine/src/cmd/*`; the UI, CLI, MCP and
scripts all call commands. To add a feature: add the command in engine, then a menu entry in `ui-egui`.

## Crate cheat-sheet (what each crate does)

WASM plug-ins), js (own ES5.1 interpreter for scripts), scriptcheck, mcp (MCP server), apischema, format (.vectorcraft),
affinity (legacy file reader), testkit.
**photo** (`apps/photo/crates/`): engine (246k), ui-egui (248k), algo (CPU filters), io (PSD/PSB + raster I/O), compose
(layers), paint (brushes), gpu, raw (camera raw), text, vector (shape layers), format (.pcraft), plugins, automation
(MCP), ipp (CUPS printing), tablet (pen pressure), color, doc, geom, ops, raster, testkit.
**pdf** (`apps/pdf/crates/`): cos (PDF object layer), render (hayro), edit, redact, sign (PAdES), forms (AcroForm),
xfa, annot, organize, optimize, ocr (`ocrs`), preflight (PDF/A), print, export (HTML/DOCX/RTF), a11y, js (boa),
compare, measure, create, crypt, filters, fonts, engine, automation (MCP), ui-egui, platform, oracle, audit, xfdf.
**film** (`apps/film/crates/`): engine, ui-egui (timeline/panels), project (document model), edit (edit algebra),
render (CPU compositor), gpu (wgpu), codecs (+isobmff, matroska, bitstream, cfb), media, export, interchange
(EDL/FCPXML/OTIO), audio-dsp, captions, speech (Whisper STT), tts, tts-text, dng, scopes, platform (HW decode),
frame, color, format (.fcproj), text, time, golden, testkit.

## Rules for edits
* Rename only user-visible strings; never rename crates/identifiers (`vectorcraft_*`, `PhotocraftApp`) — breaks merges.
* Strings in `tl!()`/English must change together with the `.tsv` key lines (keys are the English text).
* After importing upstream changes re-run `tools/rebrand.py apps/<app>` then `tools/finish_rebrand.py`.
* `xtask` policy checks (`cargo xtask ci`) still reference upstream brand files and will fail; CI here only runs `cargo build`.
* Upstream docs per app (`apps/<app>/docs/architecture.md`, `development.md`, …) are the deep reference when needed.

## platform/web (dashboard v2, no build step)
* `index.html` shell; `css/styles.css` (all styles, theme vars); `manifest.webmanifest`, `sw.js`, `icons/`.
* `js/main.js` router, shell, login, shortcuts, drag-drop. `js/store.js` DemoStore + CloudStore (same API). `js/i18n.js` hi/en strings.
* `js/ui.js` helpers (`h`, icons, modal, menu, toast). `js/data/catalog.js` apps, templates, fonts, URLs.
* Tests: `tools/test_dashboard.py`. Roadmap: `docs/ROADMAP.md`.
* `js/views/*.js`: home, projects, templates, brand, downloads, settings, shared (cards, new-project modal, import).
* Add a string → both languages in `i18n.js`. Add a template → `TEMPLATES` in catalog.js. `config.js` is generated by CI (see `config.example.js`).
* Tools: `js/views/tools.js` (TOOLS list + EXT links), `js/tools/kruti.js`, `js/tools/pdf.js`. Add a tool = add an entry to `TOOLS` with a `view()` function.
* Image tools: `js/views/tools_img.js` (`workbench()` helper + enhance/upscale/crop/bgRemove/watermark/qr/words), pixel code in `js/tools/imaging.js`, QR in `js/tools/qr.js`, amounts in `js/tools/words.js`.
* PDF tools: `js/views/tools_pdf.js` (merge/organise/compress/pdf→images), loaders for vendored libs in `platform/web/vendor/` (pdf-lib MIT, pdfjs-dist Apache-2.0; see vendor/README.md + LICENSE files). ZIP writer `js/tools/zip.js`. Barcodes `js/tools/barcode.js`. Visiting/ID card + barcode UI `js/views/tools_card.js`. `shared.js` has `pickFiles()` (multi-file).
* Cloud bridge: `platform/web/bridge.js` (loaded by `apps/{vector,photo,pdf}/apps/*-web/index.html` via `../bridge.js`); active only with `?project=<id>`. Test: `tools/test_bridge.py`.
* CI: `desktop.yml` and `web.yml` have a best-effort step that clones craft-i18n (SHA from `apps/<app>/craft-i18n.rev`) and sets `CRAFT_I18N_DIR`.
* Business tools: `js/views/tools_biz.js` (`invoiceTool`, `calcInvoice` = exact paise maths, `pdfStamp`). `tools_pdf.js` now exports `loadLib`, `readBuf`.
* OCR: `js/views/tools_ocr.js` + `vendor/ocr/` (worker, wasm cores, hin/eng models). Fonts: `vendor/fonts/` via `@font-face` at the top of `css/styles.css`.
* Poster maker: `js/views/tools_greet.js`, fonts list `js/data/deco_fonts.js`, font files `vendor/fonts/deco/`. AI: `js/views/tools_ai.js`, `platform/supabase/functions/ai-text/`, see `docs/AI.md`.
* More tools: `js/views/tools_more.js` (`paletteOf`, `makeIco`, convert, collage, `drawResume`).
* Hindi typing: `js/tools/translit.js` (+ `typingTool` at the end of `js/views/tools.js`).
* Forms: `js/views/tools_forms.js` (`fitToKB`, `formPhotoTool`, `drawCertificate`, `certificateTool`).
* CI site assembly: `tools/assemble_site.sh` (skips apps with a file over 25 MiB), used by `.github/workflows/web.yml` and `.github/workflows/site.yml` (dashboard-only deploy, no wasm).
* R2 offload for files over 25 MiB: `tools/upload_big.sh`, `functions/[[path]].js`, `wrangler.toml` (bucket `tulika-assets`, binding `BIG`); manifest `site/r2-manifest.json` is generated by `tools/assemble_site.sh`.
* Template designs/editor: `js/data/designs.js` (specs + renderer + font embedding), `js/views/editor.js`, `js/views/templates.js`; festival templates are added to `catalog.js` from `designs.js`.
- tools/audit_lang.py — EN/HI leftover-text audit; js/data/fonts_all.js, js/views/fontpicker.js — font catalogue and picker; tools/vendor_fonts.py — vendors extra OFL fonts.
- tools/audit_tools.py — sweep of every route/tool for JS errors (HI+EN).
